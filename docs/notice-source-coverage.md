# 성균관대학교 공지 수집 출처

검증일: 2026-11-12. 학교 1곳, 사이트에 표시된 단과대·학과·전공·대학원·기관 명칭 130종의 게시판 **250개**를 등록했습니다. 호스트 별칭과 동일 게시판의 카테고리 탭은 별도 출처로 세지 않습니다.

공식 대학·대학원 안내에서 연결된 사이트 250곳을 확인했습니다. 새 출처는 실제 공지 목록과 최근 공지 본문을 읽어 검증했고, 출처별 최근 글을 하나씩 기존 분류·대상 조건 처리 경로로 저장했습니다. 본교 전체 공지는 기존 자료를 그대로 통합했습니다.

초기 확인 범위는 게시판별 최근 글이며 전체 과거 글의 소급 수집이나 이미지 OCR은 하지 않았습니다. 이후 배치는 등록 출처의 최신 2페이지를 확인합니다. 마감·검토 대상 공지는 기존 화면 정책에 따라 마감 탭에서 조회합니다.

서로 다른 원문이라면 제목이 비슷해도 합치지 않습니다. 같은 게시판의 중복 카테고리 출처를 통합할 때 원문 행과 상세 URL을 보존하고, 연결이 대체된 중복 행은 목록 뷰에서 제외합니다.
